# 取材の質問シート（先生用）

たなごころの取材にご協力いただき、ありがとうございます。
このシートの **A（比較項目）** は、すべての先生に同じ形で伺い、サイト上で先生同士を並べて見られるようにします。**B（インタビュー）** は、当日お話を伺う際の目安です。

- 星・口コミ・ランキングは載せません。お金で並び順が変わることもありません。
- 「治る」「必ず良くなる」など効果を約束する言い方や、ほかの院との比較は載せられません。
- 書きにくい項目は空けたままで大丈夫です。当日一緒に考えます。

## B. インタビュー（当日伺うこと・約60分）

1. この仕事を選んだきっかけ（A4 をもう少し詳しく。そのときの情景や、人との出会い）
2. 施術でいちばん大切にしていること（A5 の背景。具体的な場面があれば）
3. 初めての人が来たとき、どんな流れで進めますか（問診で何を聞くか、不安な人への配慮）
4. 印象に残っている言葉や出来事（※ 来院者の個人が特定される話・効果の体験談は載せません）
5. どんな人に来てほしいですか。合わないかもしれない人は（A7 と合わせて）
6. 休みの日の過ごし方・最近うれしかったこと（人柄が伝わる話）
